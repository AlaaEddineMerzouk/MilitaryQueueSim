# MilitaryQueueSim

### 🪖 Military Queue Simulation with Priority & Language Support

A multilingual web application to simulate military queuing and priority systems using React and Tailwind CSS. The app supports both **queue (file)** and **stack (pile)** structures with priority logic and visual feedback.

---

## 🌐 Features

- 👨‍✈️ **Priority Queue**: Ranks higher-priority military personnel or missions.
- 📚 **Data Structures**: Simulates both queue and stack behavior.
- 🌍 **Multilingual Support**: French 🇫🇷 and Arabic 🇩🇿, with RTL support.
- 🎨 **Responsive UI**: Built with Tailwind CSS for clean and mobile-friendly design.
- ⚡ **No Backend Required**: All logic is handled client-side.
